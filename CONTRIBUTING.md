# Como contribuir

1. Abra uma issue descrevendo defeito ou melhoria.
2. Crie uma branch a partir de `main`.
3. Faça mudanças pequenas, documentadas e acompanhadas de testes quando possível.
4. Não inclua músicas, letras, senhas, chaves ou material sem licença.
5. Abra um pull request explicando comportamento anterior, mudança e como testar.

O projeto segue versionamento semântico: `MAIOR.MENOR.CORREÇÃO`.
